---
name: implement
description: Use when building a scoped piece of work from a spec or ticket, test-first, then reviewing it before you commit.
---

Implement the work described in the spec or tickets.

Use `/mattpocock-skills:tdd` where possible, at pre-agreed seams.

Run typechecking and single test files regularly, and the full test suite once at the end.

When done, review the work with `/mattpocock-skills:code-review`, then commit to the current branch. If your brief says the lead reviews or commits, the brief wins.
